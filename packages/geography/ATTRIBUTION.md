# Geography Data Attribution

Country, region, subregion, and administrative-division data is derived from:

Countries States Cities Database  
https://github.com/dr5hn/countries-states-cities-database

Licensed under the Open Database License (ODbL) v1.0.

The source data has been normalized for use by the Humanity Union Platform.

Canonical normalized datasets live in this package:

- `src/countries.json`
- `src/administrative-regions.json`
